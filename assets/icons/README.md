# 🎨 Animated Icons Guide

This directory contains animated GIF icons used across all section titles in the profile `README.md`.

You can replace any of these files at any time with animated icons downloaded directly from **[Flaticon Animated Icons](https://www.flaticon.com/animated-icons)**. Simply download the `.gif` from Flaticon and save it with the matching filename below:

| `connect.gif` | 🤝 Let's Connect & Build Together | "Handshake", "Network", "Chat", "Collaboration" |

### How to use:
1. Visit https://www.flaticon.com/animated-icons
2. Search for the icon you like.
3. Click "Download GIF" (e.g. 64px, 128px, or 256px).
4. Save / overwrite the corresponding filename in this `assets/icons/` folder.
5. Commit and push to GitHub!
